Domain:             infrastructure (Epic 0)
Parts:              infrastructure (ci); others: no
Acceptance criteria:
                    AC-1: A pull request run executes the local steps and posts a verdict; a merge run builds the images with the build id (commit) and publishes them.
                    AC-2: The wrapper only calls `ci/run` (WFL-176).
                    AC-3: Deploy steps that have no environment yet report "not available" (CIC-022).
                    AC-4: Other developers can work from Epic 0 on (D-12): branch protection on `main` requires the pull-request run to be green and one approval (human sets it); a pull-request template asks for story id, task, `ci/run all-local` result and `todo.md` update; `kickoff-prompt.md` section 1 tells a new developer how to clone, use their own Claude login and their own key in `.env`, and pass the self-test.
                    AC-5: The pull-request run uses no Anthropic key: AI tests run with the stubbed model (US-00.15); no secret is stored in GitHub for this pipeline.
Edge cases:         A failing step marks the pull request red; merging is blocked. Two developers change `todo.md` in parallel: the later pull request resolves the conflict, newest entries first.
